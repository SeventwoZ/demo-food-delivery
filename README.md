A full-stack role-playing web application that simulates restaurant design and management workflows.

Users can explore menu items, create orders, and interact with a restaurant ordering system, while administrators can manage menus, users, and order operations through an interactive dashboard.

## 🚀 Live Demo

🔗 https://fooddelivery-peach.vercel.app

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios
- React Router

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Multer (Image Upload)

---

## ✨ Features

### 👤 Customer Side

- Browse restaurant menu
- View food details
- Add items to shopping cart
- Create and manage orders
- User authentication
- Responsive user interface

### 🧑‍💼 Admin Dashboard

- Dashboard overview
- Menu management (CRUD)
- Add, update, and delete menu items
- Upload and manage food images
- Order management
- Order status tracking
- User management

## 💻 Run Locally

### Frontend

```bash
cd Frontend
npm install
npm run dev
```

### Backend

```bash
cd Backend
npm install
npm run dev
```

🔐 Environment Variables

Create a .env file inside the Backend folder:
```bash
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```
